# Team4-Sprint燃盡圖視覺化-測試案例

> 本文件彙整 SPEC-001 Sprint燃盡圖視覺化功能（AC01~AC04）之詳細測試案例，依據專案規範與 test case 撰寫指引產出。

---

| 測試案例編號 | TC-SPRINT-BURNDOWN-001 |
|--------------|------------------------|
| 測試目標 | 驗證 Sprint 燃盡圖於正常進度時正確顯示，並呈現綠色健康狀態 |
| 相關 User Story | US001: Sprint 燃盡圖視覺化與進度警示 |
| 相關 AC 場景 | AC01: Sprint 燃盡圖正常顯示與健康狀態 |
| 測試前置條件 | 1. Sprint 已啟動且進行中<br>2. Google Sheets 資料已同步，實際進度符合或超前理想進度<br>3. 使用者已登入並進入儀表板頁面 |
| 測試步驟 | 1. 進入儀表板頁面<br>2. 檢查燃盡圖是否顯示<br>3. 檢查理想線（灰色虛線）是否正確<br>4. 檢查實際線（綠色實線）是否正確顯示至當前工作日<br>5. 檢查進度條顏色是否為綠色<br>6. 檢查右上角健康狀態 badge 是否為綠色「正常進度」<br>7. 檢查完成率百分比與故事點數統計是否正確 |
| 預期結果 | 1. 燃盡圖完整顯示<br>2. 理想線為灰色虛線<br>3. 實際線為綠色實線，僅到當前工作日<br>4. 進度條為綠色<br>5. 健康狀態 badge 顯示綠色「正常進度」<br>6. 完成率與故事點數正確 |
| 測試資料 | Sprint 資料：實際進度 >= 理想進度 |
| 測試類型 | 功能測試 |
| 自動化程度 | 全自動（E2E，建議 Playwright/Cypress） |

| 測試案例編號 | TC-SPRINT-BURNDOWN-004 |
|--------------|------------------------|
| 測試目標 | 驗證燃盡圖時間邊界處理，實際線僅顯示到當前工作日，未來日期無資料點 |
| 相關 User Story | US001: Sprint 燃盡圖視覺化與進度警示 |
| 相關 AC 場景 | AC04: 燃盡圖時間邊界正確處理 |
| 測試前置條件 | 1. Sprint 為期 10 個工作日<br>2. 今天為第 8 個工作日<br>3. Google Sheets 資料已同步至第 8 天<br>4. 使用者已登入並進入儀表板頁面 |
| 測試步驟 | 1. 進入儀表板頁面<br>2. 檢查理想線是否顯示 Day 1~Day 10<br>3. 檢查實際線是否僅顯示 Day 1~Day 8<br>4. 檢查 Day 9、Day 10 無實際數據點<br>5. 將滑鼠移到 Day 9、Day 10，檢查 tooltip 內容 |
| 預期結果 | 1. 理想線顯示完整 10 天<br>2. 實際線僅到第 8 天<br>3. Day 9、10 無實際數據點<br>4. hover 未來日期時顯示「實際剩餘: 未來日期」 |
| 測試資料 | Sprint 10 天，今天第 8 天，Day 9/10 無實際資料 |
| 測試類型 | 邊界/功能測試 |
| 自動化程度 | 全自動（E2E，建議 Playwright/Cypress） |
