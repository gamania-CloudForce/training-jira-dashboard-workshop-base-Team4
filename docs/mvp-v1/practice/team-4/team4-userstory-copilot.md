# Team4 User Story (Copilot 產出)

---

**US-001**
作為產品經理，我希望 Jira 儀表板能自動標示高價值與低價值的功能項目，以便我能優先分配資源在最有價值的工作上，避免團隊浪費時間於低價值功能。

**US-002**
作為專案負責人，我希望能在儀表板上看到各功能的商業價值評分，以便快速判斷哪些任務應該優先推進。

**US-003**
作為開發團隊成員，我希望儀表板能顯示每個功能對用戶或業務的影響力，讓我能聚焦在真正重要的開發項目上。

**US-004**
作為利害關係人，我希望能一目了然地看到哪些功能屬於高價值，哪些屬於低價值，以便參與決策時有明確依據。

**US-005**
作為敏捷教練，我希望團隊能透過儀表板反思過去投入於低價值功能的比例，協助團隊持續優化工作重心。
