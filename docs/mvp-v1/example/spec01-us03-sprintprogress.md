# User Story 3: Sprint 時間進度計時器

> **檔案編號**: US-003-sprint-time-progress
> **建立日期**: 2025-09-04
> **狀態**: 草稿
> **對應 Feature Spec**: [SPEC-001-sprint-progress-v2.md](./spec01-progress-v2.md)

## 📋 Feature 背景

團隊常常對 Sprint 剩餘時間沒有明確感知，導致進度規劃不精確。需要在儀表板上顯示 Sprint 的時間進度計時器，讓成員直觀感受到時間流逝，增強對截止日期的緊迫感。

## 🎯 目標使用者角色
- 團隊成員
- Scrum Master

---

## 📝 User Story
**US003**: 作為團隊成員，我希望能看到 Sprint 的時間進度計時器（如：Day 7/10，剩餘 3 個工作日），以便直觀感受到時間的流逝，增強對截止日期的緊迫感。

---

### INVEST 品質檢查
- ✅ **Valuable**：將抽象時間概念具象化，提升時程敏感度
- ✅ **Testable**：可驗證時間計算和顯示的準確性
