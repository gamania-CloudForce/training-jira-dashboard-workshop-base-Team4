# User Story 2: Sprint 進度落後視覺警示

> **檔案編號**: US-002-sprint-progress-warning
> **建立日期**: 2025-09-04
> **狀態**: 草稿
> **對應 Feature Spec**: [SPEC-001-sprint-progress-v2.md](./spec01-progress-v2.md)

## 📋 Feature 背景

當 Sprint 進度落後時，團隊常常無法及時察覺，導致最後一刻趕工。需要在儀表板上提供明顯的視覺警示，讓團隊成員能即時感受到時程壓力，主動調整工作優先級。

## 🎯 目標使用者角色
- 開發團隊成員
- Scrum Master

---

## 📝 User Story
**US002**: 作為開發團隊成員，我希望當 Sprint 進度明顯落後時能看到明顯的視覺警示（進度條和燃盡線變為黃色或紅色），以便我能及時感受到時程壓力並主動調整工作優先級。

---

### INVEST 品質檢查
- ✅ **Valuable**：提升團隊危機感，避免最後一刻趕工
- ✅ **Testable**：可測試不同進度狀況下的警示效果
